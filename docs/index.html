About the project ↗

An automated search for Runge-Kutta methods that hold up in Q15 fixed-point arithmetic on small microcontrollers. This site is the run's live record: it is generated from the run's data at the end of every cycle, and nobody edits it by hand. The project overview explains why the project exists and how it works.
